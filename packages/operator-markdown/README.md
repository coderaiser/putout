# @putout/operator-markdownp [![NPM version][NPMIMGURL]][NPMURL]

[NPMIMGURL]: https://img.shields.io/npm/v/@putout/operator-markdownp.svg?style=flat&longCache=true
[NPMURL]: https://npmjs.org/package/@putout/operator-markdownp "npm"

🐊[**Putout**](https://github.com/coderaiser/putout) operator adds ability to work with markdown

## Install

```
npm i putout @putout/operator-markdownp
```

## API

### indentCodeblock

```js
const {operator} = require('putout');
const {indentCodeblock} = operator;

indentCodeblock(`const a = 3`);
```
